# JVM 基础详解与面试推理：Java SE 25

**导航：** [学习路线](../README.md) · [进入第 01 章](../CURRICULUM.md#第-01-章建立-jvm-与进程的全景模型)

这组内容补全主课程的基础层。阅读时先回答“程序发生了什么”，再解释“为什么这样实现”，最后用实验说明自己的判断。已有 Java 经验也建议完成字节码推演、初始化预测和引用图练习。

## 依据与讨论范围

- **规范语义**：以 [Java SE 25 Edition JVMS](https://docs.oracle.com/javase/specs/jvms/se25/html/index.html) 为虚拟机语义依据；语言层面的初始化、引用与并发规则查 Java SE 25 的 JLS。
- **实现行为**：GC、对象布局、TLAB、JVM 参数和诊断工具使用 JDK 25 官方指南，必要时核对 OpenJDK `jdk-25-ga` 源码。每个补丁版本、发行版、平台的结果仍需实测。
- **主题覆盖**：参考用户指定的 [JavaGuide JVM 入门教程](https://javaguide.cn/java/jvm/jvm-intro.html)安排基础主题；以下解释、例子与图表独立编写，不复制原文。面试题用于覆盖常见考察方向，不声称有统计意义上的出题频率。

Java SE 25 是本项目明确选择的规范版本。“最新”指在这个版本下使用正式规范与对应工具文档，不把后续 Java SE 版本的规则混进来，也不拿 JDK 8 的实现图代替 JDK 25。预览特性不作为必做内容。

本轮核对日期：2026-11-11。规范章节、API、参数与版本变更链接均在正文就近给出；其中源代码级的边界固定到 `jdk-25-ga`，厂商补丁行为需另行验证。

## 自测方式

1. 不看正文，画出一张区域图、一张调用栈图和一张对象引用图。三张图不能混为一张。
2. 随机抽每篇的面试问题。两分钟回答机制；再用五分钟讨论改变条件后的行为。
3. 每个答案至少说明一个不能由实验推出的结论，例如“未观察到回收”不能证明对象永久存活。
4. 回到 [学习进度](../PROGRESS.md)记录薄弱点。代码测试通过只说明实验语义检查通过，不代表已经掌握这些内容。

实验从仓库根目录按 [Pod 手册](../PODS.md)执行，镜像提供 JDK 25；本机开发命令才要求宿主机完整 JDK 25。
